1: Item groups limit only abilities that have a file in the AbilitySession (session.ability(id) != null); for those, skip the mob cast when allows(id, baseItemKey of the item that carries the ability) is false. An ability with no file (any MMOItems/MythicLib skill that is not ours) has no group limit and casts by the trigger rule alone. Reason: docs/phases.md:199 and the README say an ability outside its item group does nothing, but item-groups is a field of our ability files; AbilitySession.allows returns false for every id it does not know, so calling it unconditionally would block every third-party ability. Today only Dash has a file and Dash never casts for a mob, so the check is for 4b and later files.

3: A. Strip any leading namespace (everything up to and including the last ':') before comparing with "dash", ignoring case. Reason: the task says any namespace prefix; MythicLib skill ids are not namespaced, so a prefixed id can only be a spelling of the same skill, and failing safe (Dash never fires for a mob) is what #51 requires.
