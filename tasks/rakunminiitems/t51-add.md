- (medium) Recursive casts. `MobAbilityListener` casts on `EntityDamageByEntityEvent`, and a handler can deal damage synchronously inside `whenCast` with the mob as damager (e.g. `target.damage(x, mob)`). That fires `ATTACK` (and the victim's `DAMAGED_BY_ENTITY`) again from inside the cast. With a cooldown of 0 (an item modifier can set it), this recurses until a StackOverflowError. Fix: a reentrancy guard in the listener instance (a flag or depth counter set around the `getResult`/`whenCast` call, reset in `finally`); while a mob cast is running, events it causes do not start further mob casts. Add a test that pins it: a cast whose handler re-enters `castMobAbilities` (or the event handler) does not cast again, and the guard is released after a thrown RuntimeException.
- (low, 1.both.4) Remove `MobCooldowns.clearAll()`: no caller.
- (low, 1.both.1 and 1.both.3) Make the unload test call `listener.handleUnload(...)` (or `onEntitiesUnload`), and add a test for `handleShootTrident` that at least shows a player-shot trident and a non-trident projectile do nothing.
